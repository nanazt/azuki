# 도메인 용어

**로그인 유지(Login persistence)**
: Discord 인증으로 성립한 azuki 로그인 상태를 브라우저 종료나 기기 재시작을 사이에 둔 재방문에서도 이어서 사용하는 것을 뜻해요.
음악 재생이나 WebSocket 연결이 계속되는 것과는 구분해요.

**전체 로그아웃(Global logout)**
: 같은 azuki 사용자 계정의 모든 브라우저와 기기에서 로그인 상태를 종료하는 것을 뜻해요.
현재 브라우저의 쿠키만 삭제하는 동작과는 구분하며, 이미 연결된 WebSocket을 통한 접근도 포함해요.

**미접속 만료(Inactivity expiration)**
: 특정 브라우저의 azuki 로그인에 이용으로 인정되는 접속이 일정 기간 없어서 그 로그인 상태가 종료되는 것을 뜻해요.
다른 브라우저에서 같은 계정을 사용하는 것과는 구분해요.

**최대 로그인 유지 기간(Absolute session lifetime)**
: 최초 Discord 로그인부터 해당 azuki 로그인 상태를 유지할 수 있는 총기간을 뜻해요.
계속 이용하거나 로그인 자격을 갱신해도 시작 시점이 바뀌지 않아요.

**이용 중인 대시보드(Active dashboard)**
: 해당 브라우저가 화면에 표시되는 상태로 보고하는 azuki 대시보드 탭을 뜻해요.
클릭이나 키 입력은 필수가 아니며, 다른 탭 뒤에 숨겨진 상태의 자동 통신이나 WebSocket 이벤트 수신과는 구분해요.

**Discord 앱 승인(Discord app authorization)**
: Discord 웹 페이지 대신 설치된 Discord 앱의 권한 승인 화면에서 azuki의 Discord 계정 접근을 허용하는 것을 뜻해요.
Discord 앱을 단순히 실행하거나 azuki 봇을 서버에 추가하는 동작과는 구분해요.
승인 자체와 승인 결과로 azuki 웹의 로그인 상태가 성립하는 것은 별개의 단계예요.

**재생 복구(Playback recovery)**
: azuki의 음성 연결 단절이나 재시작을 사이에 두고, 듣던 곡과 중단 지점 및 남은 대기열을 이어서 사용하는 것을 뜻해요.
음성 채널에 다시 접속하는 것만으로는 재생 복구가 완료된 것이 아니에요.
재생 중이던 곡을 자동으로 이어 듣는 것과, 일시정지해 둔 곡을 정지 상태로 보존하는 것을 구분해요.

**봇 재시작(Bot restart)**
: azuki의 웹 서버와 로그인 및 재생 대기열을 유지하면서 Discord 봇 연결과 음성 처리 작업을 종료한 뒤 다시 시작하는 것을 뜻해요.
azuki 전체 프로세스나 컨테이너를 재시작하는 것과는 구분해요.
재시작 요청이 접수된 것, 봇이 Discord에 연결된 것, 음성 채널에 복귀해 재생 상태를 복구한 것은 서로 다른 단계예요.
